# 🥭 Mango Cafe

Mango Cafe is a modern restaurant landing page built using **HTML** and **CSS**. The website is inspired by tropical aesthetics and is designed to showcase a variety of mango-based desserts and beverages in an engaging and visually appealing way.

## ✨ Features

* Responsive design for desktop and mobile devices
* Hero section with parallax background
* Interactive menu cards with hover effects
* Sticky navigation bar with smooth scrolling
* "Reserve a Table" call-to-action button
* Clean and modern UI

## 🛠️ Technologies Used

* HTML5
* CSS3
* Git & GitHub
* GitHub Pages
